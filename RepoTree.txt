Production notes
----------------
- Production source of truth is the native C++ implementation in src/ and apps/,
  with platform behavior in platform/. docs/ contains operator and release
  documentation.
- CPack creates Linux and macOS CLI archives from a configured build tree; these
  are promoted into releases/native/{linux,macos}/. Windows release staging
  uses scripts/prepare_release_assets.ps1 and cmake/DeployWindows.cmake to
  assemble the GUI, CLI, and runtime dependencies; the installer is built from
  installer/DataScythe.iss. The staged release copies and archives are packaged
  production deliverables, not source-of-truth copies.
- The Windows package boundary includes GUI, CLI, and bundled Qt/runtime DLLs.
  The Linux amd64 and macOS arm64/universal v0.1.0 packages are CLI-only.
- Release artifacts and their detached signatures/checksum manifests are listed
  where shipped above. Development build trees, tests, local signing materials,
  and temporary artifacts are intentionally omitted.
